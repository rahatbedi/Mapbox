# Travel Map

A React app that shows a Mapbox map with a marker.

## Setup

Requires Node 22.13+.

1. Copy `.env.example` to `.env.local` and set `REACT_APP_MAPBOX_TOKEN` to your Mapbox public access token.
2. `npm install`
3. `npm start` to run the dev server.

## Scripts

- `npm start` – start the Vite dev server
- `npm test` – run tests with Vitest (watch mode; `npm test -- --run` for a single run)
- `npm run build` – production build into `build/`
- `npm run preview` – serve the production build locally
